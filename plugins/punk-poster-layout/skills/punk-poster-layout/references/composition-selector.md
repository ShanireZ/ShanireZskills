# 32 种构图速选表

先按内容数量和阅读任务选构图，再添加色彩、材质与风格。第一版只选一个主构图；只有当另一种关系解决不同问题时，才增加一个辅助构图。

## 快速分流

| 任务 | 优先查看 |
| --- | --- |
| 单一人物、产品、标题或品牌发布 | 01–06 平衡与焦点 |
| 权威、危险、聚焦、档案或强符号骨架 | 07–10 几何骨架 |
| 体育、音乐、科技、行动号召或流动叙事 | 11–14 动势路径 |
| 两个对象、两个观点、图像与说明分区 | 15–18 边缘、分屏与条带 |
| 文字、图片、数字、按钮等多类信息 | 19–24 网格系统 |
| 需要先决定图片还是文字当主角 | 25–28 图文关系 |
| 青年文化、实验编辑、节奏或最大主义 | 29–32 破格与密度 |

## 完整目录

| 编号 | 构图 | 主要控制 | 适用 | 关键约束 |
| --- | --- | --- | --- | --- |
| 01 | 中轴对称 Axial Symmetry | 中轴、镜像配重、中央焦点 | 品牌发布、展览、奢侈品、典礼 | 不要机械镜像每个小元素 |
| 02 | 非对称平衡 Asymmetrical Balance | 大小、明度、密度和距离的配重 | 文化、设计、时尚、科技 | 偏置必须由对侧高对比或密度回应 |
| 03 | 三分法焦点 Rule of Thirds | 三分交点、方向性留白 | 摄影、人像、产品、活动、Hero | 不为卡交点牺牲朝向或裁切 |
| 04 | 黄金螺旋 Golden Spiral | 逐级比例、弧线收束 | 艺术、自然、电影、叙事产品 | 螺旋是草图，不是成品装饰线 |
| 05 | 大留白单点 Isolated Focal Point | 65%–80% 主动留白、孤立焦点 | 高端品牌、艺术、诗歌、香氛 | 小焦点仍需足够对比与语义 |
| 06 | 边缘锚定 Edge-Anchored | 越界裁切、屏外延伸 | 时尚、人像、产品特写、社媒 | 保护脸、关节、标志和文字安全区 |
| 07 | 三角／金字塔 Triangular Hierarchy | 顶点强调、底边承重 | 群像、电影、论坛、权威发布 | 三角外不能出现更强焦点 |
| 08 | 倒三角悬置 Inverted Triangle | 高重心、向下收束 | 先锋、音乐、悬疑、警示 | 不用于可靠舒适的品牌语气 |
| 09 | 同心环绕 Concentric | 环形重复、向心聚焦 | 音乐、科技、声波、社区、周年 | 环线避开小字并保持节奏差 |
| 10 | 框中框 Frame within Frame | 嵌套边界、观看窗口 | 艺术、建筑、档案、摄影 | 框线层级不能压过文字层级 |
| 11 | 对角线动势 Diagonal Tension | 强斜轴、速度和冲突 | 体育、音乐、促销、科技 | 正文保持可读，斜轴指向有效信息 |
| 12 | 放射爆发 Radial Burst | 唯一中心、向外辐射 | 音乐节、促销、庆典、宣言 | 只保留一个放射中心 |
| 13 | Z 型路径 Z-Path | 四角锚点、顺序交接 | 活动、产品首屏、课程、发布会 | Z 是脚手架，不要直接画字母 Z |
| 14 | S 型曲线 S-Curve | 三个节点、柔性连续路径 | 美妆、时尚、舞蹈、自然、饮品 | 每次转弯都要对应信息节点 |
| 15 | L 型锚定 L-Shaped Anchor | 竖栏与横栏的角部支架 | 建筑、展览、目录、工业 | 两臂有长短差，勿封闭成四边框 |
| 16 | 左右分屏 Vertical Split | 双主题并置、60/40 主次 | 产品对比、双人、前后、联名 | 两侧必须有关联且不能完全同权 |
| 17 | 上下分屏 Horizontal Split | 图像与文字的 62/38 分区 | 电影、旅行、讲座、产品说明 | 分界避开脸部、文字中线和关键结构 |
| 18 | 水平带状 Horizontal Bands | 4–6 条不等带宽、章节节拍 | 音乐、交通、体育、时间表 | 条带不能等宽等强，正文行长要可读 |
| 19 | 单栏手稿网格 Single-Column Grid | 连续主栏、线性阅读 | 宣言、文学、学术、演讲 | 海报不是论文页，控制行长和段数 |
| 20 | 多栏编辑网格 Multi-Column Grid | 等宽栏、重复沟槽、跨栏层级 | 会议、课程表、目录、数据说明 | 不要让每个元素随机跨栏 |
| 21 | 模块网格 Modular Grid | 行列矩阵、跨模块组合 | 瑞士风格、日程、系列视觉 | 网格是底层关系，不必全部画出来 |
| 22 | 瑞士非对称网格 Swiss Grid | 左齐右不齐、功能性层级 | 设计、建筑、音乐会、文化机构 | 红圆与 Helvetica 不能替代结构 |
| 23 | 层级卡片网格 Bento | 卡片面积表达优先级 | 科技、功能、数据、服务、落地页 | 同层卡片保持相同语义与间距 |
| 24 | 棋盘交替 Checkerboard | 图文交替、反转与一个破例 | 系列产品、阵容、对照、时尚 | 矩阵勿过细，必须有一个主焦点 |
| 25 | 满版主视觉 Full-Bleed Hero | 沉浸图像、局部文字安全区 | 电影、旅行、时尚、摄影、人物 | 不把字压在脸或复杂纹理上 |
| 26 | 大字主导 Typographic Dominant | 超尺度标题、字形裁切 | 观点、宣言、音乐、促销、议题 | 断行保留语义，只用少数字体 |
| 27 | 图上叠字 Type over Image | 字在前、字在后或明确穿插 | 时尚、杂志、电影、音乐 | 不用整行半透明文字含混层级 |
| 28 | 双联／三联 Diptych / Triptych | 共同变量、连续画幅 | 前后、系列、群像、摄影展 | 无关图片并排不构成双联或三联 |
| 29 | 拼贴层叠 Overlapping Collage | 4–7 层、受控旋转、遮挡 | 音乐、青年文化、杂志、复古 | 统一材质、配色或叙事线索 |
| 30 | 破格网格 Broken Grid | 先建网格，再让少数元素跨线 | 先锋、科技、实验编辑、作品集 | 80% 元素守规则，只破格一次 |
| 31 | 重复节奏 Repetition & Pattern | 规则阵列、单一异常项 | 系列、群体、音乐、运动、数据 | 只让一个元素因主题需要而破例 |
| 32 | 密集全铺 Dense All-Over | 多尺度层级、有限色盘 | 节日、地下音乐、潮流、复古广告 | 密集仍要有标题与 CTA 入口 |

## 组合规则

把主构图写成全局骨架，把辅助构图写成局部阅读关系，不要让两个构图争夺同一职责。

- `三分法 + S 型曲线`：主视觉落在三分交点，三个辅助节点沿曲线连接。
- `模块网格 + 破格标题`：内容块遵守 4×6 模块，只有标题跨出一条边界。
- `满版主视觉 + 图上叠字`：图像决定整体场域，文字穿插只解决前后层级。
- `左右分屏 + 非对称平衡`：分屏建立对比，对侧的小型高对比信息块负责配重。

如果两个名称都试图决定全画面的焦点、网格或阅读路径，删除一个。
